# Художник-склеротик

HTML5-игра (Vite + TypeScript, без фреймворков), рассчитана на телефон в вертикальной ориентации, работает и на компьютере.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/, озвучка копируется туда же
```

## Устройство

| Файл | Что внутри |
| --- | --- |
| `src/main.ts` | Запуск: стартовый экран → видео (пока грузится музыка и шрифты) → «Включите звук» → главный экран |
| `src/menu.ts` | Главный экран: баллы, следующий раунд, «Как играть», пройденные раунды с переигровкой |
| `src/tutorial.ts` | Обучающий ролик `video/tutorial.mp4`: сам при первом запуске и по кнопке «Как играть» |
| `src/round.ts` | Раунд: экраны подготовки → диктовка → 30 секунд → опрос по 9 ячейкам → итоги |
| `src/board.ts` | Поле 5×5 на canvas: камера, маркер, переходы между ячейками |
| `src/audio.ts` | Музыка, голос (Web Audio) и простые звуковые эффекты |
| `src/content.ts` | Раунды из `voiceover/manifest.json`, подписи «Диктует …» |
| `src/answer.ts` | Сравнение ответа: без регистра, «е/ё», пунктуации и пробелов |
| `src/progress.ts` | Прогресс в `localStorage` |
| `src/ads.ts` | Заглушка рекламы |
| `video/tutorial/` | Обучающий ролик: сценарий (`SCRIPT.md`), запись экрана игры (`record_ui.mjs`), сцены из Gemini Omni и сборка `make_tutorial.py` |

Номер ячейки в опросе вырезается из `dictation.mp3` по таймингам манифеста, поэтому в сборку попадают только `dictation.mp3` и `lines/*.wav` каждого раунда.

## Отладка

В режиме `npm run dev` в консоли браузера доступны `__round.skip()` (завершить диктовку или 30 секунд) и `__audio`. Сбросить прогресс: `localStorage.clear()`.
