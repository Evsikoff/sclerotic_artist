# Обучающее видео «Как играть»

75 секунд, вертикальное 720×1280, 30 кадров в секунду. Главное в ролике — как пользоваться полем:
приблизить ячейку, рисовать, отменить линию, перейти к другой ячейке, догнать голос, закончить раньше и ответить в опросе.
Поэтому середина ролика — запись настоящей игры, а не рисованный интерфейс.

| Часть | Длина | Откуда |
| --- | --- | --- |
| Знакомство | 8 с | Gemini Omni 1.2 Flash (`gemini-omni-1.2-flash`): художник в студии |
| Как играть | 60 с | Запись экрана игры: раунд 10 в dev-сборке, телефон 360×640 при DPR 2 (`record_ui.mjs`) |
| Финал | 7 с | Gemini Omni 1.2 Flash |

Части склеены наплывом 0,4 с: в конце знакомства камера наезжает на телефон в руках художника,
и его экран растворяется в настоящем интерфейсе.

- **Голос** — один диктор на весь ролик, Gemini TTS (`gemini-3.8-flash-tts`, голос Laomedeia), реплика на каждое действие.
  Художник в кадре молчит.
- **Голос раунда** — настоящая озвучка раунда 10 («Три… Улыбка», «Шесть», номера в опросе) из `voiceover/rounds/round_10`.
- **Звуки игры** — «верно» и «неверно», те же тоны, что в `src/audio.ts`.
- **Музыка** — трек игры `music/Midday_at_the_Atelier.mp3`, тихо под всем роликом.

## Сборка

```
npm run dev
set GEMINI_API_KEY=...
python -X utf8 video/tutorial/make_tutorial.py voice      # реплики диктора -> voice/, длины -> voice/lines.json
python -X utf8 video/tutorial/make_tutorial.py record     # запись игры -> clips/02-gameplay.mp4 и .json, refs/phone-screen.png
python -X utf8 video/tutorial/make_tutorial.py video      # сцены Omni -> clips/01-intro.mp4, clips/03-finale.mp4
python -X utf8 video/tutorial/make_tutorial.py check      # нет ли в сценах Omni речи или музыки
python -X utf8 video/tutorial/make_tutorial.py assemble   # -> video/tutorial.mp4
```

`record` идёт в реальном времени (около полутора минут) и запускает установленный Microsoft Edge без окна через `playwright-core`.
Запись не тратит API. Кадры и разметка лежат в `.state/ui`; `record --render-only` пересобирает клип без новой записи.
Порядок важен: запись ждёт длины реплик из `voice/lines.json`, а сценам Omni нужен `refs/phone-screen.png` из записи.

## Запись экрана (`record_ui.mjs`)

Игра настоящая. Скрипт только двигает «палец» (кружок поверх страницы, при касании сжимается и пускает круг),
заранее рисует часть ячеек и управляет временем диктовки через `__round` из dev-сборки:
держит подсветку на нужной ячейке, пока диктор объясняет, и перематывает к номеру, который должно быть слышно.
Звук страница не пишет — его собирают по событиям из разметки.

| Время | Диктор | На экране |
| --- | --- | --- |
| 0:00 | Вот поле: двадцать пять ячеек с номерами. | Поле, №1 и №2 уже нарисованы, подсвечена №2 |
| 0:04 | Голос называет номер — и ячейка загорается… | |
| 0:07 | *(голос раунда)* «Три… Улыбка» | Загорается №3 |
| 0:11 | …а следом звучит слово. Его и рисуем! | |
| 0:14 | Коснитесь ячейки — она приблизится. | Палец касается №3, ячейка приближается |
| 0:17 | Рисуйте прямо пальцем. | Палец рисует смайлик |
| 0:24 | Лишняя линия? «Отменить» уберёт последнюю. | Палец черкает зигзаг и нажимает «Отменить» |
| 0:27 | Стрелка — к следующей ячейке. | Голос перешёл к №4; стрелка «№4» |
| 0:30 | «Отдалить» — снова всё поле. | «Отдалить» |
| 0:32 | *(голос раунда)* «Шесть» | Подсвечена №6, игрок отстал |
| 0:33 | Отстали от голоса? Кнопка с динамиком перенесёт к ячейке, о которой он уже договорил. | Кнопка с динамиком ведёт к №5 |
| 0:40 | Список закончился? Есть ещё тридцать секунд, чтобы дорисовать. | Всё поле нарисовано, кроме №8; «Осталось 0:30» |
| 0:44 | Закончили раньше — жмите «Готово». | «Готово» → «Рисунок готов!» |
| 0:47 | *(голос раунда)* «Три» | Опрос: «Что было в ячейке №3?» |
| 0:48 | Потом голос спросит про девять ячеек. Вспомните слово и впишите его. | Палец вводит «улыбка», «Ответить» |
| 0:54 | Верно — плюс балл! | «Верно! +1» |
| 0:55 | *(голос раунда)* «Восемь» | «Что было в ячейке №8?» — она пустая |
| 0:56 | Не вспомнили или ошиблись — минус балл. | «Не помню» → «Правильный ответ: «Скорлупка». −1» |

Время указано от начала записи; в ролике к нему прибавляется 7,6 с знакомства.
Опрос в игре выбирает ячейки случайно: скрипт подменяет `Math.random` на один проход перемешивания,
чтобы первыми спросили №3 и №8. Между отрезками («рисование», «30 секунд», «опрос») — склейка встык,
вырезаны только ожидания (реплика игры перед опросом).

Рисунки в ячейках соответствуют словам раунда 10 и заданы линиями в `DOODLES`. Ячейка №8 («Скорлупка») пустая:
на ней показан ответ «Не помню».

## Сцены Omni

Референсы: художник (`refs/artist.jpg`), студия (`refs/studio.jpg`) и кадр игры для экрана телефона (`refs/phone-screen.png`).
Промпты — в `make_tutorial.py` (общий стиль `STYLE` и действие каждой сцены).

| № | Сцена | Длина | Диктор | В кадре |
| --- | --- | --- | --- | --- |
| 1 | Знакомство | 8 с | Это художник-склеротик. Рисует он лихо, а вот память — дырявая! Сейчас покажу, как играть. | Художник входит, заносит маркер над холстом и забывает, что хотел нарисовать. Чешет затылок, достаёт телефон и показывает экран в камеру; камера наезжает на экран с игрой. |
| 2 | Финал | 7 с | Так что рисуйте понятно — и память не подведёт! Готовы? Берите маркер! | Художник смотрит в телефон и хлопает себя по лбу, смеётся, убирает телефон, берёт маркер, протягивает его зрителю и подмигивает. |

Проверка `check`: речи и музыки в сценах нет, только шаги, шорох, сигнал телефона и пара невнятных междометий
(«хм», вздох) — под диктором их почти не слышно.

## Известные огрехи

- Экран телефона в сценах Omni похож на игру, но мелкие подписи на нём нарисованы приблизительно.
- На экране записи — «Раунд 10»: показан настоящий раунд с его голосом и словами.
